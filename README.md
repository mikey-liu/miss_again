# miss_again

这是一个微信小游戏开发项目。

当前游戏：《铁锅套大鹅》

## 当前实现

已实现一版可玩的《铁锅套大鹅》核心游戏：

- 启动页、主菜单、关卡地图、战斗页、结算页。
- 拖动铁锅上滑蓄力，松手按抛物线飞出。
- 大鹅会在地图中移动，需要预判路线和铁锅落点。
- 已接入白鹅、花鹅、奔跑鹅、大胖鹅、金鹅、老板鹅。
- 支持命中、未命中、连击、金币、能量条和主动锅技。
- Boss 关需要多次命中老板鹅。
- 支持铁锅升级、菜谱升级、餐馆升级和餐馆收益领取。
- 关卡胜利后自动解锁下一关。
- 已生成并接入《铁锅套大鹅》专用地图、精灵、图标和音频素材。

PRD 见 [docs/铁锅套大鹅.txt](docs/铁锅套大鹅.txt)。

核心素材见 [assets/iron_goose](assets/iron_goose)。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选择本仓库。
3. 编译类型选择“小游戏”，使用已有 `project.config.json`。
4. 点击编译后即可在模拟器中运行。

## 本地验证

核心状态机、关卡规则、投掷、命中、升级和收益逻辑可以在 Node.js 下验证：

```bash
node tests/run-core-tests.js
```

重新生成《铁锅套大鹅》图片和音频素材：

```bash
python scripts/generate_iron_goose_assets.py
```

## 主要文件

- `game.js`：微信小游戏 Canvas 渲染、触控、音频和页面交互。
- `src/gameCore.js`：核心状态机、关卡、投掷物理、命中、升级和收益逻辑。
- `tests/run-core-tests.js`：核心逻辑测试。
- `assets/iron_goose/`：当前游戏使用的运行时素材。
