# Audio Assets

These WAV files are generated locally by `scripts/generate_audio_assets.py`.

| File | Usage |
| --- | --- |
| `bgm_loop.wav` | Looping warm chiptune background music |
| `ui_click.wav` | Button and UI tap feedback |
| `throw_whoosh.wav` | Ring throw release |
| `ground_thud.wav` | Light ground bounce |
| `veggie_bounce.wav` | Stronger target collision bounce |
| `hit_success.wav` | Successful ring catch |
| `miss_blip.wav` | Miss or too-short swipe |
| `result_jingle.wav` | Level result screen |

The current files are prototype audio assets. They are intentionally short, mono, and low sample rate to keep the mini game package small.
