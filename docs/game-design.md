# 《又没中？！》游戏方案

## 1. 定位

《又没中？！》（Miss Again?!）是一款轻量休闲微信小游戏。核心体验是“操作简单、结果微妙、失败也有趣”：玩家通过短促的滑动/瞄准动作完成投掷、射箭、射击等小游戏，物理反馈要让玩家觉得“差一点就中了”，从而愿意立刻再试一次。

当前版本先实现“套圈”玩法，射箭和射击作为大厅入口占位。

## 2. 主流程

1. 载入界面
   - 展示游戏名、像素风进度条、简短提示。
   - 自动进入游戏列表。

2. 游戏列表
   - 展示三个模式：套圈、射箭、射击。
   - 套圈可进入；射箭和射击显示“开发中”。

3. 套圈关卡地图
   - 展示关卡节点。
   - 第一关默认可玩；第二关可玩但规则更难；后续关卡占位。

4. 套圈关卡
   - 每关 5 个圈。
   - 玩家从屏幕底部圆环处上滑蓄力，松手后投出。
   - 圆环落地或命中后消耗 1 个圈。
   - 5 个圈用完后展示结算，可返回地图或重玩。

## 3. 套圈玩法规则

### 第一关：新手摊位

- 目标：套中任意瓜果蔬菜即可得分。
- 物体较大，摆放较松。
- 上滑时显示当前滑动距离。
- 命中后播放像素粒子特效。
- 地面第一次碰撞轻微弹跳，碰到蔬菜弹跳更明显。

### 第二关：小目标挑战

- 目标：套中更小的物体。
- 不显示当前手指滑动距离，只显示蓄力条。
- 物体半径更小，摆放更分散。
- 保持与第一关一致的重力、阻力和弹跳规则，只调整目标尺寸和容错。

## 4. 物理手感

当前版本采用轻量 2D 物理：

- 重力恒定，所有关卡共用同一套重力参数。
- 圆环发射速度由手指上滑距离决定。
- 圆环水平速度由横向滑动偏移决定。
- 碰到屏幕边缘会反弹并衰减。
- 第一次落到地面时轻微弹跳，之后更快停稳。
- 碰到瓜果蔬菜时使用更高的弹跳系数，制造“弹走了”的反馈。
- 圆环中心靠近目标中心，且处于下落阶段时判定为套中。

后续如果需要更真实的刚体表现，可以接入 Matter.js 或自研更完整的 2.5D 投掷模型。

## 5. 像素风视觉

临时美术策略：

- 使用 Canvas 绘制像素风块状图形，不依赖外部图片。
- 统一低饱和草地、摊位、木牌、瓜果蔬菜配色。
- 图形尽量使用整数坐标和矩形块，少用渐变。
- 圆环保留清晰描边，命中后增加亮色粒子。
- UI 使用简单面板、像素按钮、短文案。

## 6. 版本拆分

### 当前迭代

- 完成载入界面、游戏列表、套圈地图、第一关、第二关。
- 套圈关卡支持 5 个圈、滑动蓄力、距离显示规则、命中得分、粒子特效、结算。
- 射箭和射击仅做入口占位。

### 下一迭代

- 增加更多关卡配置和解锁条件。
- 增加音效、震动和更丰富的失败反馈。
- 增加道具、目标权重、连击奖励。
- 做主菜单和关卡地图的正式像素美术。

### 后续玩法

- 射箭：拉弓蓄力、风向、靶心倍率。
- 射击：准星抖动、后坐力、手机震动反馈。
- 投篮：抛物线投篮、篮筐碰撞、连中挑战。
