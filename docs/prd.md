# 《又没中？！》微信小游戏 PRD

版本：v0.1

适用阶段：MVP 到 Alpha 版本开发  
项目代号：Miss Again?!

## 1. 产品概述

### 1.1 产品定位

《又没中？！》是一款像素风轻量休闲微信小游戏。玩家通过简单的滑动、瞄准、松手操作挑战不同小游戏，核心情绪是“就差一点”“再来一次”。游戏不追求复杂数值，而追求短局、强反馈、低门槛和可反复挑战。

### 1.2 核心卖点

- 操作简单：单指滑动即可完成主要操作。
- 反馈明确：命中、弹开、擦边、落地都有可见反馈。
- 失败有趣：失败不是静态失败，而是通过物理弹跳制造“差点中”的感觉。
- 模式扩展：先做套圈，后续扩展射箭、射击、投篮等同类物理小游戏。
- 风格统一：整体定位像素风，UI、目标物、特效都使用块状像素语言。

### 1.3 当前版本目标

当前版本只要求完整实现“套圈”玩法，其余小游戏只做入口占位。

必须完成：

- 载入界面。
- 游戏列表。
- 套圈入口。
- 套圈关卡地图。
- 套圈第 1 关和第 2 关。
- 每关 5 个圈。
- 上滑蓄力投掷。
- 第 1 关显示滑动距离。
- 第 2 关隐藏滑动距离，并缩小目标物。
- 圆环物理：重力、落地轻弹、碰到蔬菜更大弹跳。
- 命中特效。
- 关卡结算。

非当前版本范围：

- 射箭正式玩法。
- 射击正式玩法。
- 商业化广告。
- 账号成长系统。
- 复杂背包和道具系统。
- 联网排行榜。

## 2. 目标用户与体验目标

### 2.1 目标用户

- 微信小游戏轻度玩家。
- 喜欢短局挑战、失败重试、物理反馈类小游戏的用户。
- 可接受像素风视觉的休闲用户。

### 2.2 单局体验目标

- 单局时长：30 秒到 90 秒。
- 学习成本：首次进入 5 秒内理解“上滑投圈”。
- 失败反馈：玩家应能理解自己为什么没中，例如力度小、偏左、弹走。
- 重试成本：失败后 1 秒内可继续下一圈。
- 第一关通关率：新手应较容易套中至少 1 次。
- 第二关难度：明显比第一关难，但不应显得随机。

## 4. 用户流程

### 4.1 首次进入流程

```text
打开小游戏
-> 展示载入页
-> 自动进入游戏列表
-> 点击“套圈”
-> 进入套圈关卡地图
-> 点击“第 1 关”
-> 进入关卡
-> 上滑蓄力
-> 松手投掷
-> 命中/未命中
-> 剩余圈数减少
-> 5 个圈用完
-> 结算
-> 重玩或返回地图
```

### 4.2 关卡内循环

```text
等待投掷
-> 玩家按住并上滑
-> 显示蓄力反馈
-> 松手
-> 圆环飞行
-> 碰撞地面/蔬菜/边界
-> 判定命中或停稳未命中
-> 播放反馈
-> 若还有圈，进入下一次投掷
-> 若没有圈，进入结算
```

## 7. 规则与数值建议

### 7.1 投掷输入

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| 最小有效上滑距离 | 36 px | 低于该值不发射，不消耗圈 |
| 最大上滑距离 | 220 px | 超过后按最大力度计算 |
| 纵向速度系数 | 5.0 到 6.0 | 距离转为上抛速度 |
| 横向速度系数 | 3.5 到 4.5 | 横向偏移转为水平速度 |
| 初始额外上抛 | 100 到 140 | 保证手感更轻快 |

### 7.2 物理参数

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| 重力 | 1600 到 1800 | 所有关卡一致 |
| 空气阻力 | 0.990 到 0.996 | 每帧水平速度衰减 |
| 墙面反弹 | 0.35 到 0.50 | 不能太弹 |
| 首次地面反弹 | 0.20 到 0.32 | 轻微弹跳 |
| 后续地面反弹 | 0.08 到 0.16 | 快速停稳 |
| 蔬菜反弹 | 0.60 到 0.75 | 明显高于地面 |
| 停稳速度 | 80 到 110 | 低于该速度结束 |

### 7.3 命中判定

命中应满足：

- 圆环处于下落阶段。
- 圆环中心靠近目标中心。
- 距离小于目标判定半径。
- 目标未被套中过。

建议判定：

```text
distance(ring.center, target.center) <= target.radius * 0.58
ring.vy > 0
```

### 7.4 得分规则

MVP 推荐简单分值：

- 大目标：1 分。
- 稍难目标：2 分。
- 小目标：2 到 3 分。
- 5 个圈总分用于结算评价。

评价建议：

| 得分 | 评价 |
| --- | --- |
| 0 | 又没中？！ |
| 1-2 | 有点手感 |
| 3-5 | 套圈高手 |
| 6+ | 摊主沉默了 |

## 9. 状态机

### 9.1 应用状态

```text
loading
-> menu
-> ringMap
-> ringGame
```

### 9.2 套圈局内状态

```text
ready
-> aiming
-> flying
-> hit
-> ready

ready
-> aiming
-> flying
-> miss
-> ready

hit/miss
-> finished   当 ringsLeft = 0
```

状态说明：

- ready：等待玩家开始上滑。
- aiming：玩家正在拖动蓄力。
- flying：圆环飞行中，禁止再次操作。
- hit：命中，等待点击继续。
- miss：未命中，等待点击继续。
- finished：关卡结束，展示结算。

### 10.1 风格

- 低分辨率块状图形。
- 不使用复杂渐变。
- 不使用写实素材。
- 图形边缘清晰。

### 10.3 UI 规范

- 按钮使用矩形像素边框。
- 卡片不做大圆角。
- 标题字号大于普通文案。
- 交互按钮区域必须大于 44x44 px。
- 游戏内关键文本不超过一行，避免遮挡玩法区域。

## 11. 音效与震动规划

## 14. 验收标准

当前版本完成的定义：

- 微信开发者工具中可从启动进入完整主流程。
- 游戏列表、套圈地图、关卡、结算页均可正常交互。
- 第 1 关和第 2 关规则差异明确。
- 每关固定 5 个圈。
- 合法投掷会消耗圈，短距离滑动不会消耗圈。
- 命中能得分并触发特效。
- 未命中能自然结束并继续。
- 所有关卡使用一致重力。
- 地面弹跳轻，蔬菜弹跳更明显。
- UI 视觉统一为像素风。
- 核心逻辑有自动化测试覆盖。

## 15. 后续扩展方向

### 15.1 射箭

核心规则：

- 按住拉弓。
- 左右微调角度。
- 松手射箭。
- 加入风向和靶心倍率。

### 15.2 射击

核心规则：

- 拖动准星。
- 准星轻微抖动。
- 点击射击。
- 加入后坐力和震动。

### 15.3 投篮

核心规则：

- 上滑投篮。
- 篮筐碰撞。
- 空心、擦板、弹框不同反馈。

## 16. 风险与注意事项

- 物理不能过于随机，否则玩家会觉得不公平。
- 第 2 关隐藏距离后必须保留蓄力条，否则难度会变成盲猜。
- 目标物变小后要同步调整命中容错，避免完全套不中。
- 结算和继续操作必须非常快，不能打断短局节奏。
- 像素风要统一，不要混入写实素材或过多渐变。
- 如果后续接入 Matter.js，需要评估包体积和微信小游戏兼容性。
